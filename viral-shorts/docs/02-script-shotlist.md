### Comment bait (rule #6) — how it works
Line 18 contains two intended errors:
1. **"Mars is the coldest planet"** — false. Neptune is coldest (≈ −214 °C); Mars averages ≈ −63 °C. Correctors will flood the comments.
2. **"cooling there is easy"** — false for a vacuum, which is exactly what the video just explained (no air = no convection). Second wave of commenters will explain this back to the video.
Pinned reply to use after upload: *"you're right — Neptune is colder 🥶 one point for science"*.

### Delivery notes for the VO
- Speed 1.08–1.12× a normal read; no pauses longer than 250 ms inside a line.
- Line 8 "Why?" is a hard, fast turn — the word before it drops in pitch.
- Line 11 "Free power forever." is the only relaxed line in the video (false comfort).
- Line 17 is quieter, not louder — doubt sells the climax.
- Line 19 lifts and pushes forward so the loop feels like it restarts mid-sentence.
